🧾 Validate This Camera Result

Independently inspect the processed camera frame. Select what a human reviewer considers correct, not what the AI displays. Each unique captured frame can be submitted only once; the saved prediction is tied to that exact frame.

A vehicle detection updates the live counters automatically, but it does not increase Verified Frames. To measure accuracy, compare all four AI outputs with the real scene and click Save Human-Verified Sample. Never copy the AI prediction into the actual-answer fields without checking it.

Start the camera in Auto mode before saving a validation sample. New validation samples must be at least 5 seconds apart.
